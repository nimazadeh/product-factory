# تحلیل Stripe — ۲۰۲۶-۱۰-۲۰
> روش: خواندن زندهٔ stripe.com (هیرو، بنتو، نوار اعداد، مشتریان)، تحلیل‌های اعتماد/تبدیل و الگوی Stripe Elements/Checkout.
> چرا برای ما: مرجع جهانی «لندینگ ابزار + اعتمادسازی با عدد» — دقیقاً مسئلهٔ لندینگ و فاکتورساز پولی آیندهٔ دست‌افزار.

## ۱) فلسفه
1. **یک جمله، یک دسته‌بندی:** هیرو محصول را توضیح نمی‌دهد، دسته را تعریف می‌کند: «زیرساخت مالی برای رشد درآمدت» — بعد دو CTA (شروع / با گوگل).
2. **ادعا با عدد، نه صفت:** نوار اعتماد با ۴ عدد سخت: ۱۳۵+ ارز، $1.9T حجم ۲۰۲۵، آپتایم ۹۹٫۹۹۹٪، ۲۰۰M+ اشتراک. هر عدد قابل راستی‌آزمایی است.
3. **مشتریِ نام‌دار با داستان و عدد خودش:** Hertz ‏(۱۶۰ کشور)، URBN ‏($5B درآمد)، هر مشتری: لوگو + عدد نتیجه + محصولات استفاده‌شده + لینک داستان کامل — اثبات چندلایه، نه دیوار لوگوی مرده.
4. **گرادیان امضادار = استدلال بصری:** موج رنگی متحرک هیرو تزئین نیست؛ قبل از خواندن یک کلمه می‌گوید «دقیق، فنی، زنده» — و فقط همان یک نقطهٔ پرهزینهٔ صفحه است، بقیه ساکت‌اند.

## ۲) آناتومی لندینگ (به‌ترتیب اسکرول)
1. هیرو: تیتر دسته‌ساز + زیرتیتر یک‌خطی + ۲ CTA + ویژوال محصول/گرادیان.
2. بنتو گرید قابلیت‌ها: هر خانه یک قابلیت با مینی‌دموی زنده (کنتور توکن، کارت صدور…) — قابلیت «نشان داده» می‌شود.
3. نوار اعداد (۴ عدد) — بعد از فهم محصول، قبل از اثبات مشتری.
4. مشتریان سازمانی (آکاردئون داستانی) + شبکهٔ مشتریان کوچک‌تر با عدد نتیجه («رسید به $100M ARR»).
5. مسیر دوگانهٔ مخاطب: توسعه‌دهنده (کد و داک وسط مارکتینگ) و مدیر (عدد و داستان) بدون اینکه هم را خفه کنند.

## ۳) درس‌های اعتماد (از پژوهش تبدیل)
- عدد مشخص همیشه صفت مبهم را می‌برد («استفاده‌شده توسط ۴۲۷ کسب‌وکار» > «مورد اعتماد بهترین‌ها»).
- اثبات اجتماعی کنار نقطهٔ تصمیم بیشترین اثر را دارد، نه بالای صفحه به‌تنهایی؛ در موبایل اثبات فشرده کنار CTA.
- امتیاز کامل ۵٫۰ از ۴٫۰–۴٫۷ کمتر می‌فروشد — کمال، ساختگی خوانده می‌شود؛ صداقت عددی خودش اعتماد است.
- رنگ برند (بنفش ‎#635BFF) فقط برای: دکمهٔ اصلی، حالت فعال، موفقیت — رنگ = اکشن، هر جای دیگر ممنوع.

## ۴) چی را می‌دزدیم — نقشهٔ دست‌افزار
| الگوی Stripe | اعمال در دست‌افزار |
|---|---|
| تیتر دسته‌ساز + ۲ CTA | لندینگ ما: یک تیتر + CTA اصلی «دیدن ابزارها» (داریم، تیزتر شود) |
| نوار ۴ عدد سخت | وقتی عدد واقعی داشتیم: «۵ ابزار، ۰ ثبت‌نام، ۱۰۰٪ محاسبه روی دستگاه، ۰ داده ذخیره‌شده» — عددهای محصول خودمان، نه قرضی |
| بنتو با مینی‌دموی زنده | کارت‌های ابزار لندینگ: هر کارت یک نتیجهٔ زندهٔ کوچک (مثلاً مبدل با تاریخ امروز پر شده) به‌جای آیکن+متن مرده |
| رنگ فقط برای اکشن | سبز ما فقط: CTA، حالت فعال، موفقیت نتیجه — بقیه خنثی (نزدیکیم؛ قانون شود) |
| یک نقطهٔ پرهزینه، بقیه ساکت | هیرو یک حرکت/ویژوال شاخص؛ بقیهٔ صفحه بی‌حرکت (پولیش v0.4.3 ما همین راه است ✓) |
| اثبات کنار تصمیم | صفحهٔ فاکتورساز آینده: کنار دکمهٔ پرداخت — امنیت/بدون ذخیره/پشتیبانی، نه فوتر |

## ۵) نقد صادقانه — چه چیز را نمی‌گیریم
- Stripe به شرکت ۱۵ساله با مشتری Fortune 100 تکیه دارد؛ ما عدد قرضی و لوگوی جعلی نمی‌سازیم (قانون خودمان: متن بازاریابی = فایدهٔ واقعی).
- گرادیان WebGL برای ابزار فارسی سبک ما سنگین است؛ نسخهٔ ما: یک ویژوال شاخصِ سبک (تقویم زندهٔ امروز) به‌جای افکت.
- دولاین مخاطب (dev/مدیر) نداریم؛ تک‌مخاطبیم و این سادگی مزیت ماست.
