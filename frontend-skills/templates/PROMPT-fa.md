## نسخه کامل (برای شروع یک وب‌اپ جدید)

```
وب‌اپ [نام و توضیح یک‌خطی محصول، مثلاً: داشبورد مدیریت مالی برای کسب‌وکارهای کوچک] را بساز.

الزامات غیرقابل مذاکره:
- طبق فایل frontend-skills/00-MASTER-production-frontend/SKILL.md پیش برو و اسکیل‌های داخل frontend-skills/skills/ را هرجا لازم بود باز کن (به‌خصوص 01-ui-ux-pro-max برای Design System).

- Production-Ready در حد سازمانی (Enterprise): TypeScript strict، Design System با توکن (DESIGN.md بساز)، کامپوننت‌های قابل استفاده مجدد.
- همه stateها: loading (skeleton)، empty، error با retry، success و permission.
- Accessibility در سطح WCAG 2.2 AA: کیبورد، فوکوس مشخص، لیبل، کنتراست.
- ضد AI-slop: بدون گرادیان بنفش پیش‌فرض و کارت‌های جنریک؛ یک جهت هنری مشخص انتخاب و اول کار اعلام کن.
- مخاطب/کاربران: [مثلاً مدیران مالی، فارسی‌زبان، RTL لازم است/نیست]
- Stack: [مثلاً Next.js + Tailwind + shadcn/ui — یا: خودت بهترین را پیشنهاد بده]

روند کار:
1) اول Design Contract + DESIGN.md را بنویس و نشانم بده.
2) بعد پیاده‌سازی کن و Preview زنده بده.
3) آخر کار Verification Gate مستر اسکیل را اجرا کن و گزارش بده در چه breakpointهایی (320/768/1024/1440) تست کردی.
```
