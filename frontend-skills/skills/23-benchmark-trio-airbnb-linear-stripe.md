# Skill 23 — بنچمارک سه‌گانه: Airbnb (تقویم) · Linear (سرعت) · Stripe (اعتماد)

> قانون استفاده: الگو را بدزد، پوست را نه. کپی پیکسلی ممنوع (قانون همیشگی).

## A) Airbnb — انتخاب تاریخ و تقویم
1. ابزار اصلی بالای صفحه است، نه توضیحش؛ کاربر در ۵ ثانیه اول دارد کار می‌کند.
2. فیلد چندبخشی: لیبل کوچک داخل فیلد + مقدار زیرش؛ فوکوس خودکار به فیلد بعدی بعد از تکمیل (با گارد remount — درس v0.6.1 دست‌افزار).
3. روز تقویم = ماتریس وضعیت مکتوب: default/hover/selected/in-range/disabled/today — هیچ وضعیت بداهه‌ای نداریم.
4. رفتار لبه‌ها تعریف‌شده است: انتخاب اشتباه = ری‌استارت قابل پیش‌بینی، نه پیام خطای سرزنش‌گر.
5. تاریخ «تقویمی» است نه timestamp: سه‌تایی (سال،ماه،روز) یا رشتهٔ ISO؛ محاسبه روی اجزای تقویم.
6. انعطاف را عددی کن: چیپ‌های آماده («امروز»، «اول ماه بعد») به‌جای واداشتن کاربر به تایپ.

## B) Linear — سرعتِ حس‌شده و میکرواینترکشن بی‌صدا
1. اول رندر کن، بعد هر کاری: نتیجه از دادهٔ لوکال/محاسبهٔ روی دستگاه؛ اسپینر برای کار آنی ممنوع.
2. حرکت فقط `transform` و `opacity`؛ مدت‌ها: میکرو ۱۰۰ms، استاندارد ۱۵۰ms، صفحه ≤۲۵۰ms، ease-out ‏(0.16,1,0.3,1)؛ انیمیتِ layout-property ممنوع.
3. بازخورد فشردن: `active: scale(.97)` روی دکمه و روز تقویم.
4. سکوت بصری: سلسله‌مراتب با تایپوگرافی و فاصله؛ قاب و سایه آخرین ابزارند.
5. ریتم تراکم واحد: ارتفاع ردیف/گپ لیست‌ها از یک توکن (Skill 22).
6. Empty State = یک جملهٔ مطمئن؛ بدون عذرخواهی و متن بازاریابی.
7. کیبورد: میانبر فقط وقتی محصول پاوريوزری شد؛ تا آن روز فوکوسِ درست و ترتیب Tab بی‌نقص واجب است (Skill 22 بخش ۸).

## C) Stripe — لندینگ ابزار و اعتماد
1. تیتر، دسته را تعریف می‌کند نه ویژگی را؛ یک تیتر + حداکثر ۲ CTA.
2. اعتماد = عدد سختِ قابل راستی‌آزمایی از محصول خودمان؛ صفت مبهم و عدد قرضی ممنوع (صداقت فنی).
3. قابلیت را نشان بده: کارت ابزار با نتیجهٔ زندهٔ کوچک > آیکن + متن مرده.
4. رنگ برند فقط برای اکشن/فعال/موفقیت؛ بقیهٔ صفحه خنثی.
5. یک نقطهٔ پرهزینه (حرکت/ویژوال شاخص در هیرو)؛ بقیهٔ صفحه ساکت.
6. اثبات کنار نقطهٔ تصمیم می‌نشیند (کنار CTA/پرداخت)، نه فقط فوتر.

## گیت قبل از تحویل (هر سه با هم)
- [ ] کار اصلی در ۵ ثانیهٔ اول قابل انجام است؟ (Airbnb)
- [ ] هیچ اسپینر/انیمیشن layout برای کار آنی نیست؟ مدت حرکت ≤۲۵۰ms؟ (Linear)
- [ ] هر ادعای لندینگ عدد واقعی محصول خودمان است؟ رنگ فقط روی اکشن است؟ (Stripe)
