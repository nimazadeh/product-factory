# Logo Design
## Process
1. **Brief**: نام، صنعت، شخصیت، رقیب، کاربرد اصلی (اپ آیکون؟ چاپ؟) — قالب در `../templates/brand-brief.template.md`
2. **۳ جهت کانسپت** (کلامی، قبل از تصویر): مثلاً Wordmark تایپوگرافیک / نماد هندسی / مونوگرام — هرکدام با دلیل اتصال به محصول
3. **ساخت**: برای نمادهای ساده و مقیاس‌پذیر، **SVG دستی ترجیح دارد** (وکتور واقعی، تیز در هر سایز). برای کانسپت‌های تصویری پیچیده از `generate_image` با `offer_options=true` استفاده کن؛ خروجی رستری فقط کانسپت است و نسخه نهایی باید به وکتور بازطراحی/ردیابی شود.
   - پرامپت تصویر باید شامل: سبک تخت وکتوری، پس‌زمینه ساده، بدون متن اضافی/موکاپ/گرادیان شلوغ باشد.
4. **تست مقیاس**: ۱۶px (favicon)، ۴۸px (اپ)، چاپ تک‌رنگ — در هر سه باید خوانا بماند؛ نسخه تک‌رنگ (mono) جدا بساز.
5. **Logo Pack تحویلی**: `logo.svg` (رنگی/تک‌رنگ/معکوس)، `logo-*.png` (512/192)، `favicon.svg/ico`، اپ‌آیکون، + صفحه کاربرد درست/غلط در Guidelines.
## Rules
- حداکثر ۲ رنگ در نماد اصلی؛ بدون افکت سه‌بعدی/سایه سنگین؛ Clear-space = ارتفاع یک حرف از لوگوتایپ دور لوگو؛ حداقل سایز چاپ ۸mm / دیجیتال ۲۴px
- ⚠️ تحویل = پیش‌نویس حرفه‌ای؛ قبل از ثبت/استفاده تجاری: بررسی trademark و طراح انسانی.
