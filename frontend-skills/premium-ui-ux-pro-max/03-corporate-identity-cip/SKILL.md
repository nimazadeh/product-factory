# Corporate Identity Program (CIP)
چک‌لیست کامل ۵۰ قلم در `../templates/cip-checklist.template.md` — برای هر پروژه فقط اقلام لازم را تیک بزن.
## دسته‌ها
چاپ اداری (سربرگ A4، پاکت، کارت ویزیت 85×55mm، فاکتور) · دیجیتال (ایمیل سیگنچر، قالب سوشال، کاور) · محیطی (ساینیج، بیلبورد، غرفه) · محصول (پکیجینگ، لیبل، یونیفرم/خودرو) · ارائه (اسلاید مستر، قالب گزارش)
## Rules هر قلم
- مشخصات تولید صریح: سایز، bleed=3mm و CMYK برای چاپ / sRGB و px برای دیجیتال، حاشیه امن، نسخه فارسی/انگلیسی جدا در صورت نیاز
- فقط توکن‌های برند (زیراسکیل 08)؛ هیچ رنگ/فونت خارج از سیستم وارد CIP نمی‌شود
- خروجی: فایل editable (SVG/HTML/PPTX) + خروجی نهایی (PDF چاپی/PNG) در `assets/cip/<item>/`
## QA
- [ ] در همه اقلام یک خانواده بصری خواناست  - [ ] مشخصات چاپ/دیجیتال روی هر فایل نوشته شده  - [ ] نسخه تک‌رنگ برای چاپ اداری تست شد
