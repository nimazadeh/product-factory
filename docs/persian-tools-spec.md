# Spec — «گاه‌یار» (GaahYar) · جعبه‌ابزار تاریخ فارسی

> وضعیت: Spec v1 — ۲۰۲۶-۱۰-۱۹ · متد: Matt Pocock (Grill → Spec → Tickets → TDD → Review)
> محصول دوم مونوریپو `product-factory` — پوشه: `gaahyar/`

## ۱) مسئله
فارسی‌زبان‌ها (به‌ویژه خارج از ایران) روزانه برای کارهای ساده تاریخی جستجو می‌کنند:
«تبدیل تاریخ شمسی به میلادی»، «سن من به شمسی»، «تا نوروز چند روز مونده». ابزارهای موجود
پراکنده، زشت، پرتبلیغ یا انگلیسی‌اند. یک جای تمیز و سریع فارسی وجود ندارد.

## ۲) مخاطب و بازار
- فارسی‌زبان، فقط فارسی (تصمیم Grill ‏۲۰۲۶-۱۰-۱۹)
- ورود اصلی: جستجوی گوگل (SEO) — هر ابزار = یک صفحه قابل ایندکس با عنوان فارسی

## ۳) نسخه ۱ — پک تاریخ (۴ ابزار)
1. **مبدل تاریخ** شمسی ↔ میلادی (دوجهته، تقویم جلالی خودمان — دارایی آماده جیبتو)
2. **محاسبه سن** دقیق (سال/ماه/روز) از تاریخ تولد شمسی یا میلادی
3. **فاصله دو تاریخ** (به روز/هفته/ماه/سال — هر دو تقویم)
4. **شمارش معکوس نوروز و مناسبت‌ها** (نوروز، یلدا، مهرگان…) — ابزار وایرال/اشتراک‌گذاری

هر ابزار: صفحه جدا (URL جدا برای SEO)، نتیجه آنی بدون دکمه، کپی نتیجه، بدون ثبت‌نام.

## ۴) صریحاً خارج از نسخه ۱ (Non-goals)
- بک‌اند، حساب کاربری، دیتابیس (Local-First؛ تاریخچه اخیر فقط localStorage)
- زبان انگلیسی، اپ موبایل، تقویم کامل ماهانه، قیمت/ارز
- تبلیغات در روز لانچ (بعد از ترافیک فعال می‌شود)

## ۵) مدل درآمد (Freemium)
- رایگان: هر ۴ ابزار، بدون محدودیت و بدون تبلیغ در شروع
- پریمیوم (فاز ۲، بعد از اثبات ترافیک): تبدیل گروهی (چند تاریخ با هم)، خروجی ICS
  برای افزودن به تقویم گوگل/اپل، یادآور تولد شمسی، بدون تبلیغ
- قیمت‌گذاری و درگاه: تصمیم فاز ۲ (وابسته به جغرافیای کاربران واقعی)

## ۶) لندینگ و برند
- نام: **گاه‌یار** — فارسی، حرفه‌ای/خنثی (تصمیم Grill)
- لندینگ: Hero تمیز با خودِ مبدل در همان نگاه اول (ابزار اول از همه)، کارت ابزارها،
  بخش «چرا گاه‌یار»، FAQ سئومحور، فوتر مینیمال
- استاندارد ساخت: design-exploration گیت (skill 18) → Master فرانت → ممیزی skill 13
  شامل ممیزی هندسی؛ Vazirmatn، RTL، تقویم جلالی طبق قوانین workspace

## ۷) استک (تصمیم تازه‌ای لازم نیست — ADR موجود)
- فرانت: Vite + React + TS (همان جیبتو)، `jalaali-js`، استقرار استاتیک
- بک‌اند: ندارد (در صورت نیاز فاز ۲: ADR یعنی NestJS+PostgreSQL)
- تست: Vitest برای منطق تاریخ + Playwright (ممیزی ۱۵+ تست جیبتو الگوست)

## ۸) معیار موفقیت نسخه ۱
- ایندکس‌شدن ۵ صفحه در گوگل + اولین ۱٬۰۰۰ بازدید ارگانیک
- هر ابزار < ۱ ثانیه تا نتیجه، Lighthouse ‏۹۰+
- نرخ اشتراک‌گذاری شمارش معکوس نوروز (سیگنال وایرال)
