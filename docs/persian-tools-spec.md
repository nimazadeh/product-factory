# Spec — «دست‌افزار» (Dastafzar) · پلتفرم جعبه‌ابزار فارسی

> وضعیت: Spec v2 — ۲۰۲۶-۱۰-۱۹ (بازنویسی پس از تصمیم کاربر: پلتفرم کامل، نه فقط تاریخ)
> متد: Matt Pocock (Grill → Spec → Tickets → TDD → Review) · محصول دوم مونوریپو — پوشه: `dastafzar/`

## ۱) مسئله و فرصت
فارسی‌زبان‌ها هر روز برای کارهای کوچیک دیجیتال جستجو می‌کنند: تبدیل تاریخ، ساختن فاکتور،
عدد به حروف، محاسبه اقساط… ابزار موجود یا انگلیسی است، یا زشت و پرتبلیغ، یا (مثل
PersianToolbox با ۱۰۰+ ابزار) کمّی است و تخصصی/پولی نیست. **جای خالی بازار: کیفیت و
ابزار تخصصیِ قابل پرداخت** — نه ابزار صدم.

## ۲) مدل پلتفرم: «لبه باریک ← گسترش» (قانون ضدپخش‌شدن)
- **فاز ۱ — لبه ورود (رایگان · ترافیک SEO):** پک تاریخ — مبدل شمسی↔میلادی، محاسبه سن،
  فاصله دو تاریخ، شمارش معکوس نوروز/مناسبت‌ها
- **فاز ۲ — تخصصی پولی (اولین ستاره):** فاکتورساز حرفه‌ای فارسی — رایگان با واترمارک،
  خروجی تمیز/بدون واترمارک + قالب‌های حرفه‌ای پولی
- **فاز ۳ — دسته‌های تازه فقط با داده فازهای قبل:** متن (عددبه‌حروف، فینگلیش)،
  محاسبه‌گرها (اقساط، درصد و تخفیف، حقوق و دستمزد) — هر دسته وقتی قبلی ترافیک گرفت

قانون: هیچ دسته تازه‌ای قبل از اثبات دسته قبلی شروع نمی‌شود.

## ۳) مخاطب و زبان
فارسی‌زبان (فقط فارسی در v1) — ورود اصلی گوگل؛ هر ابزار یک صفحه SEO مستقل.

## ۴) استک (تصمیم Grill ۲۰۲۶-۱۰-۱۹)
- **Next.js (App Router, SSG)** — چون سوخت محصول SEO است: HTML آماده برای گوگل،
  متادیتای فارسی هر صفحه، sitemap خودکار. (جیبتو SPA می‌ماند؛ ابزار درست برای هر کار.)
- React + TS (همان مهارت)، `jalaali-js` و JalaliDatePicker آماده از جیبتو
- Local-First در v1: بدون بک‌اند/حساب؛ تاریخچه در localStorage
- فاز پولی: بک‌اند طبق ADR (`docs/backend-stack-ADR.md`: NestJS+PostgreSQL) + درگاه متناسب با جغرافیای کاربران

## ۵) برند و لندینگ
- نام: **دست‌افزار** — واژه اصیل فارسی به معنی ابزار؛ یونیک، فرهنگی، بدون برند مستقیم هم‌نام
- شعار کاری: «هر کاری، یه ابزارش اینجاست»
- لندینگ: Hero کلین با جستجوی ابزار + ابزار پرچم‌دار (مبدل) در نگاه اول، دسته‌ها،
  ابزارهای محبوب، FAQ سئومحور — استاندارد: گیت design-exploration (skill 18) پیش از کد

## ۶) درآمد
- رایگان: ابزارهای پایه، بدون تبلیغ در شروع (اعتماد اول)
- پریمیوم: خروجی‌های حرفه‌ای (فاکتور بدون واترمارک، قالب پریمیوم)، تبدیل گروهی، بدون تبلیغ
- تبلیغ فقط بعد از ترافیک معنادار روشن می‌شود
