# تاریخچه نسخه‌ها — دست‌افزار

## v0.6.0 — ۲۰۲۶-۱۰-۲۰
- **پولیش کامل همه صفحات ابزار** با آناتومی نتیجه یکدست (برچسب ← مقدار اصلی ← زیرنویس/چیپ) هم‌خانواده با تقویم:
  - مبدل: تاریخ میلادی درشت + روز هفته + دکمه کپی با آیکن Lucide
  - محاسبه سن: تایل‌های سال/ماه/روز + مجموع روزهای عمر
  - فاصله دو تاریخ: عدد درشت + چیپ‌های هفته و ماه
  - نوروز: شمارش زنده روز/ساعت/دقیقه/ثانیه (تیک ۱ ثانیه) + اشتراک با آیکن، ایموجی‌ها حذف شدند
- ورودی‌های شمسی: placeholder راهنما و حالت invalid قرمز با aria-invalid (مثل ماه ۹۹)
- ToolShell تازه: لینک بازگشت «همه ابزارها» با پیکان متحرک + ناوبری پایینی موبایل در همه صفحات ابزار با آیتم فعال درست (ابزارها/تقویم)
- ممیزی زنده هر ۵ ابزار: overflow=۰، ایموجی=هیچ، محاسبات راستی‌آزمایی شد (سن ۳۰/۱/۱۳ = ۱۱٬۰۰۲ روز؛ فاصله سال ۱۴۰۵ = ۳۶۴ روز)؛ E2E ‏۹/۹، تست واحد ۸/۸

## v0.5.0 — ۲۰۲۶-۱۰-۲۰
- **پولیش تقویم پرچم‌دار:** ترنزیشن جهت‌دار تعویض ماه، جمعه‌ها قرمز، روز مناسبت‌دار با پس‌زمینه گرم، دکمه «امروز» کپسولی، سطر اطلاعات ماه، کارت نتیجه با سلسله‌مراتب تازه (تاریخ درشت ← معادل میلادی ← بج مناسبت با آیکن Lucide ← فاصله) — ایموجی 🎉 حذف شد
- **پولیش داشبورد ادمین (الگوی shadcn):** فازهای کامل login/loading/ready/error — اسکلتون شیمر (۱۷ بلوک، aria-busy)، حالت خالی برای هر ۴ لیست، صفحه خطا با تلاش دوباره، فرم ورود Fieldمحور (لیبل+آیکن+خطای زیر فیلد) و دکمه ورود با اسپینر
- نوارهای استفاده و نمودار روزانه با ترنزیشن نرم؛ همه حرکت‌ها ایمن با prefers-reduced-motion
- ممیزی زنده با API واقعی: لاگین مدیر، اسکلتون حین بارگذاری، حالت خالی (۴ Empty)، تقویم (۳۰ روز، ۴ جمعه، ۱ مناسبت، ترنزیشن ماه)؛ E2E ‏۹/۹
